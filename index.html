Backup & restore

Your data is encrypted and saved in this browser on this computer. Backups are encrypted with your password too, so they're safe to keep in cloud storage or email to yourself. Use Automatic backup below so a copy is kept without you remembering.

Automatic backup to a folder

Pick a folder once (ideally one that syncs — OneDrive, Google Drive, Dropbox, iCloud). After every change, an encrypted backup is written there automatically, plus a dated copy each day (the last 30 days are kept).

Not set up

Automatic folder backup needs Chrome or Edge. In this browser, use Download backup now regularly — the program will remind you every 7 days.

iPhones don't allow automatic folder backup. Tap Back up now at least weekly (you'll be reminded): it opens the share sheet — choose Save to Files → iCloud Drive, or email it to yourself. To combine this phone's entries with your computer, open that backup on the computer and use Merge from backup.

Danger zone

Removes everything, including the password. Backup files are not affected.

How this program works

This is a single file that runs in your web browser. Nothing is sent to the internet. Your clients and time entries are encrypted with your password and stored by the browser on this computer only.

Daily use

  1. Add clients first (Clients tab): name, hourly rate, file number. Each client can have a different rate.
  2. Record time (Time Log tab): choose the client, date, how the contact happened (phone, email, text, meeting…), how long it took, and a short description. Click Add entry.
  3. Live calls: press Start on the timer when the call begins and Stop when it ends — the minutes fill in automatically.
  4. Billing rules (Settings): choose your increment (6-minute / 0.1 hr is standard), a minimum charge per contact, and your tax rate. Time is rounded up to the increment.
  5. Invoice (Invoice tab): pick the client, optionally a date range, click Preview, then Print / Save as PDF. Click Mark these entries as billed so they don't appear on the next invoice.
  6. Export: the Time Log's Export CSV button gives you a spreadsheet of whatever is currently filtered.

Your password

You set it the first time you open the program. It cannot be reset or recovered. If you forget it, the only way back is a backup file plus the password that backup was made with. Write the password down and keep it with your other firm credentials. The program locks itself after a period of inactivity (Settings → Security) and whenever you click Lock.

Never lose your data — set this up on day one

  1. Go to Settings & Backup → Automatic backup to a folder and click Choose backup folder….
  2. Pick (or create) a folder inside a synced location — OneDrive, Google Drive, Dropbox or iCloud Drive. That way a copy also exists off this computer.
  3. Done. From now on, every change writes an encrypted backup there, plus one dated copy per day (30 days kept). Backup files are encrypted, so they're safe even if someone else sees the folder.

Browsers ask you to re-approve the folder each time you open the program; a yellow bar appears with a one-click Re-enable button. If you use Safari or Firefox, the folder feature isn't available — use Download backup now weekly instead (you'll be reminded).

On an iPhone

  1. Open the program's web address in Safari.
  2. Tap the Share button, then Add to Home Screen.
  3. Open it from the new icon and create your password there. It now works offline and keeps its data on the phone, encrypted.
  4. Tap Back up now weekly and choose Save to Files → iCloud Drive.

Using it on both phone and computer

The phone and computer each keep their own copy. To combine them:

  1. On the phone, tap Back up now and save the file to iCloud Drive (or email it to yourself).
  2. On the computer, go to Settings & Backup → Merge from backup… and choose that file. New entries are added, edits take the newest version, and deletions carry over. Nothing is duplicated.
  3. To send the computer's entries to the phone, do the same the other way round.

Merge combines. Restore replaces everything — use it only for a new device or recovery.

Moving to a new computer / recovering

  1. Copy this file and your latest backup file (Billable-Time-Tracker-backup-LATEST.json) to the new computer.
  2. Open the file, click restore from a backup on the lock screen, choose the backup file, and enter the password it was made with.

Good habits

  • Keep this file in one place (for example your Documents folder) and open it from there each time. Opening copies from different folders can look like separate, empty programs in some browsers.
  • Use Chrome or Edge for the full feature set.
  • Don't clear your browser's "site data / cookies" without first downloading a backup — that is where the program keeps its data.
